### 🔴 CRÍTICO — [menu_principal.gd líneas 23–29 y 66]

**Problema 1**: Botones @onready usados directamente sin null check — crash si algún nodo no existe en escena

**Reproduce cuando**: La estructura de la escena no coincide con los NodePaths declarados (renombrar un nodo, cambiar la jerarquía, o cargar la escena con nodos faltantes). El crash ocurre en `_ready()` inmediatamente al cargar la escena.

```gdscript
# ANTES (malo): crash si $VBox/BtnJugar no existe
@onready var btn_jugar: Button = $VBox/BtnJugar
# ...en _ready():
btn_jugar.pressed.connect(_jugar_local)     # ← NullReferenceError si btn_jugar es null
btn_host.pressed.connect(_iniciar_host)     # ← ídem
btn_unirse.pressed.connect(_unirse_a_partida)  # ← ídem

# DESPUÉS (correcto): verificar cada @onready crítico
func _ready() -> void:
    if not btn_jugar or not btn_multijugador or not btn_salir:
        push_error("MenuPrincipal: botones del menú no encontrados — verifica la escena")
        return
    btn_jugar.pressed.connect(_jugar_local)
    btn_multijugador.pressed.connect(_toggle_panel_multi)
    btn_salir.pressed.connect(_salir)

    if not btn_host or not btn_unirse:
        push_error("MenuPrincipal: botones de multijugador no encontrados")
        return
    btn_host.pressed.connect(_iniciar_host)
    btn_unirse.pressed.connect(_unirse_a_partida)

    if panel_multijugador:
        panel_multijugador.hide()
```

**Problema 2**: `input_ip.text` accedido sin null check en `_unirse_a_partida()`

### 🟡 ADVERTENCIA — [outline_controller.gd líneas 79–89 y 92–96]

**Problema**: `pulse()` y `highlight_for()` usan `await` sobre timers dentro de un bucle; si el nodo es liberado mientras corren (e.g. enemigo muerto mientras su outline parpadea), el siguiente intento de acceso lanzará `"Attempt to call function on a previously freed instance"`.

**Reproduce cuando**: Se llama `pulse()` sobre un enemigo y ese enemigo recibe `queue_free()` antes de que la duración expire.

```gdscript
# ANTES (malo): no hay guardia contra nodo liberado
while elapsed < duration:
    if visible:
        show_outline(color)
    else:
        hide_outline()
    visible = not visible
    await get_tree().create_timer(interval).timeout  # ← si self fue freed, error aquí
    elapsed += interval

# DESPUÉS (correcto): comprobar validez tras cada await
while elapsed < duration:
    if visible:
        show_outline(color)
    else:
        hide_outline()
    visible = not visible
    await get_tree().create_timer(interval).timeout
    if not is_instance_valid(self) or not is_inside_tree():
        return  # nodo liberado, abortar silenciosamente
    elapsed += interval

# Aplicar el mismo patrón a highlight_for():
func highlight_for(duration: float = 1.0, color: Color = Color.YELLOW) -> void:
    show_outline(color)
    await get_tree().create_timer(duration).timeout
    if not is_instance_valid(self) or not is_inside_tree():
        return
    hide_outline()
```

### 🟡 ADVERTENCIA — [menu_principal.gd líneas 56–74]

**Problema**: `_iniciar_host()` y `_unirse_a_partida()` cambian de escena aunque NetworkManager esté ausente o falle. Resultado: el nivel se carga sin conexión de red establecida, el juego queda en estado inconsistente (modo "multijugador" sin red).

**Reproduce cuando**: NetworkManager no está registrado como Autoload (configuración incompleta del proyecto) y el jugador pulsa Host o Unirse.

```gdscript
# ANTES (malo): change_scene se llama pase lo que pase
func _iniciar_host() -> void:
    var nm := get_node_or_null("/root/NetworkManager")
    if nm and nm.has_method("host_game"):
        nm.host_game(PUERTO)
    else:
        push_warning("MenuPrincipal: NetworkManager no disponible, iniciando sin red")
    get_tree().change_scene_to_file(NIVEL_INICIAL)  # ← siempre se ejecuta

# DESPUÉS (correcto): no cambiar escena si la red no está lista
func _iniciar_host() -> void:
    var nm := get_node_or_null("/root/NetworkManager")
    if nm and nm.has_method("host_game"):
        nm.host_game(PUERTO)
        get_tree().change_scene_to_file(NIVEL_INICIAL)
    else:
        push_error("MenuPrincipal: NetworkManager no disponible — no se puede iniciar partida")
        # Aquí mostrar feedback al jugador (label de error, etc.)
```

### 🔵 MEJORA — [music_layers.gd línea 176]

**Problema**: `silence(duration)` acepta un parámetro `duration` pero lo ignora completamente; siempre usa `fade_duration`. La firma de la función promete algo que no cumple.

```gdscript
# ANTES (confuso):
func silence(duration: float = 1.0) -> void:
    set_state(STATE_SILENT, true)  # duration nunca se usa

# DESPUÉS (correcto, opción A — usar el parámetro):
func silence(duration: float = 1.0) -> void:
    var prev_fade := fade_duration
    fade_duration = duration
    set_state(STATE_SILENT, true)
    fade_duration = prev_fade

# Opción B — eliminar el parámetro si no hay intención de usarlo:
func silence() -> void:
    set_state(STATE_SILENT, true)
```

### 🔵 MEJORA — [outline_controller.gd línea 23, screen_transition_controller.gd línea 26]

**Problema**: Ambos usan `get_node(path)` en `@onready` en vez de `get_node_or_null(path)`. En Godot 4 `get_node()` imprime un error en consola si el path no existe, aunque ambos archivos sí verifican null en `_ready()`. Solo estética de código, pero genera ruido en el log de errores.

```gdscript
# ANTES:
@onready var _sprite: Sprite2D = get_node(sprite_path)

# DESPUÉS:
@onready var _sprite: Sprite2D = get_node_or_null(sprite_path)
```
