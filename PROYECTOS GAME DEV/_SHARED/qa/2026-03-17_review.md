### 🔴 CRÍTICO — [2026-03-17_beat_sync.gd línea 20 y 24]
**Problema**: División por cero si `bpm` se configura a 0 en el Inspector.
**Reproduce cuando**: El desarrollador pone `bpm = 0` en el Inspector (o lo deja en cero por accidente). El juego crashea en `_ready()` o en `set_bpm()`.
**Fix**:
```gdscript
# ANTES (malo):
func _ready() -> void:
    _beat_duration = 60.0 / bpm

func set_bpm(new_bpm: float) -> void:
    bpm = new_bpm
    _beat_duration = 60.0 / bpm

# DESPUÉS (correcto):
func _ready() -> void:
    if bpm <= 0.0:
        push_error("BeatSync: bpm debe ser mayor que 0. Usando 120 por defecto.")
        bpm = 120.0
    _beat_duration = 60.0 / bpm

func set_bpm(new_bpm: float) -> void:
    if new_bpm <= 0.0:
        push_error("BeatSync: bpm inválido (%f). Ignorado." % new_bpm)
        return
    bpm = new_bpm
    _beat_duration = 60.0 / bpm
```

### 🔴 CRÍTICO — [2026-03-17_sfx_library.gd línea 154]
**Problema**: Mismatch de tipos con AudioManager. `SFXLibrary.play()` llama `AudioManager.play_sfx(stream, bus)` pero `AudioManager.play_sfx()` espera `(event: String, pitch: float, volume_db: float)`. Esto causa un error de tipo en runtime cuando el AudioManager está presente.
**Reproduce cuando**: Se llama `SFXLibrary.play("player_jump")` en cualquier momento durante el juego con el AudioManager activo como Autoload.
**Fix**:
```gdscript
# ANTES (malo):
    AudioManager.play_sfx(stream, bus)  # tipos incorrectos: stream es AudioStream, no String

# DESPUÉS (correcto): usar pool propio, sin depender del API de AudioManager
func play(event: String, bus: String = "SFX") -> void:
    var stream := get_stream(event)
    if stream == null:
        push_warning("SFXLibrary: stream no encontrado para evento '%s'" % event)
        return
    var player := AudioStreamPlayer.new()
    add_child(player)
    player.stream = stream
    player.bus = bus
    player.play()
    player.finished.connect(player.queue_free)
```

### 🔴 CRÍTICO — [2026-03-17_hit_flash_controller.gd líneas 46-50]
**Problema**: `flash_rapid()` nunca ejecuta más de un flash. Después de la primera llamada a `flash()`, la flag `_flashing = true` bloquea todas las llamadas siguientes del loop. El efecto de flash rápido (daño fuerte) no funciona.
**Reproduce cuando**: Llamas `hit_flash_controller.flash_rapid(3)` — solo se ve 1 flash en lugar de 3.
**Fix**:
```gdscript
# ANTES (malo):
func flash_rapid(count: int = 3, interval: float = 0.08) -> void:
    for i in count:
        flash()                                        # 2do y 3er call bloqueados por _flashing = true
        await get_tree().create_timer(interval).timeout

# DESPUÉS (correcto):
func flash_rapid(count: int = 3, interval: float = 0.08) -> void:
    for i in count:
        if not _sprite or not _sprite.material:
            return
        _sprite.material.set_shader_parameter("flash", true)
        _sprite.material.set_shader_parameter("flash_intensity", flash_intensity)
        await get_tree().create_timer(flash_duration).timeout
        _sprite.material.set_shader_parameter("flash", false)
        await get_tree().create_timer(interval).timeout
```

### 🔴 CRÍTICO — [2026-03-17_player_state_machine.gd línea 108] y [2026-03-17_shooting_system.gd línea 105]
**Problema**: `_physics_process()` procesa Input directamente sin verificar `is_multiplayer_authority()`. En multiplayer, todos los peers ejecutan este código, lo que significa que el input local controla a TODOS los personajes simultáneamente.
**Reproduce cuando**: Dos jugadores conectados — el jugador 1 presiona una tecla y mueve tanto su personaje como el del jugador 2.
**Fix**:
```gdscript
# ANTES (malo):
func _physics_process(delta: float) -> void:
    if current_state == State.DEAD:
        return
    _update_timers(delta)
    # ... input processing sin authority check

# DESPUÉS (correcto):
func _physics_process(delta: float) -> void:
    if current_state == State.DEAD:
        return
    if not is_multiplayer_authority():
        return  # solo el dueño del nodo procesa input
    _update_timers(delta)
    _update_gravity(delta)
    _process_state(delta)
    was_on_floor = is_on_floor()
    move_and_slide()
    _check_state_transitions()
```

### 🟡 ADVERTENCIA — [2026-03-17_powerup.gd líneas 80, 97, 110]
**Problema**: Los tres efectos de power-up nunca se aplican. Los guards verifican `player.has_method("add_speed_boost")`, `player.has_method("add_shield")`, `player.has_method("add_air_jump")` — ninguno de estos métodos existe en `player_state_machine.gd`. El power-up se recoge, desaparece y no pasa nada.
**Reproduce cuando**: El jugador toca cualquier power-up. Se dispara la señal `collected` pero el jugador no recibe ningún efecto.
**Fix**:
```gdscript
# ANTES (malo):
func _apply_speed_boost(player: Node) -> void:
    if not player.has_method("add_speed_boost"):  # este método no existe en player_state_machine
        return

# DESPUÉS (correcto): verificar la propiedad directamente
func _apply_speed_boost(player: Node) -> void:
    if not "run_speed" in player:
        push_warning("PowerUp: player no tiene propiedad 'run_speed'")
        return
    var original_speed = player.run_speed
    player.run_speed *= 1.5
    await get_tree().create_timer(effect_duration).timeout
    if is_instance_valid(player):
        player.run_speed = original_speed
```

### 🟡 ADVERTENCIA — [2026-03-17_camera_smooth.gd líneas 93-106]
**Problema**: La función `shake()` usa `await` dentro de callbacks de un Tween (`tween_callback`), lo que no funciona como se espera. Los callbacks de Tween son síncronos — el `await` no suspende el tween. El efecto de shake no se ejecuta.
**Reproduce cuando**: Se llama `camera.shake()` al recibir daño. La cámara no tiembla.
**Fix**:
```gdscript
# ANTES (malo):
func shake(intensity: float = 0.2, duration: float = 0.15) -> void:
    var original_pos = global_position
    var tween = create_tween()
    for i in range(int(duration * 60)):
        var offset = Vector2(randf_range(-intensity, intensity), randf_range(-intensity, intensity))
        tween.tween_callback(func(): global_position = original_pos + offset)
        tween.tween_callback(func(): await get_tree().process_frame)  # no funciona en tween_callback

# DESPUÉS (correcto):
func shake(intensity: float = 0.2, duration: float = 0.15) -> void:
    var original_pos = global_position
    var tween = create_tween()
    var steps = int(duration * 30)
    var step_time = duration / steps
    for i in steps:
        var offset = Vector2(randf_range(-intensity, intensity), randf_range(-intensity, intensity))
        tween.tween_callback(func(): global_position = original_pos + offset)
        tween.tween_interval(step_time)
    tween.tween_callback(func(): global_position = original_pos)
```

### 🟡 ADVERTENCIA — [2026-03-17_checkpoint.gd línea 60]
**Problema**: `_update_visual()` es llamada desde `_ready()` y accede a `sprite.self_modulate` sin verificar null. Si el nodo `$Sprite2D` no existe en la escena (nombre incorrecto, nodo faltante), crash al cargar la escena.
**Reproduce cuando**: La escena del checkpoint tiene el sprite con un nombre diferente a "Sprite2D", o si falta el nodo.
**Fix**:
```gdscript
# ANTES (malo):
func _update_visual() -> void:
    if _activated:
        sprite.self_modulate = Color.GREEN  # crash si sprite es null

# DESPUÉS (correcto):
func _update_visual() -> void:
    if not sprite:
        push_warning("Checkpoint: falta $Sprite2D")
        return
    if _activated:
        sprite.self_modulate = Color.GREEN
        sprite.scale = Vector2.ONE * 1.2
    else:
        sprite.self_modulate = Color.WHITE
        sprite.scale = Vector2.ONE
```

### 🟡 ADVERTENCIA — [DialogueTriggers.gd líneas 562-573]
**Problema**: En `_ejecutar_secuencia()`, el SFX de cada diálogo se reproduce DESPUÉS de esperar la duración completa del diálogo, no cuando el diálogo empieza. El sonido suena al terminar el texto, no al mostrarlo.
**Reproduce cuando**: Se dispara cualquier trigger con `secuencia: true` (ej: `thanatos_aparece`). Los sonidos de papel/sello suenan justo cuando aparece la SIGUIENTE línea de diálogo.
**Fix**:
```gdscript
# ANTES (malo):
func _ejecutar_secuencia(dialogos: Array) -> void:
    for dialogo_config in dialogos:
        if _dialogue_manager:
            _dialogue_manager.mostrar_dialogo(dialogo_config)
            await get_tree().create_timer(dialogo_config.get("duracion", 2.0)).timeout
        if dialogo_config.has("sfx"):      # SFX reproducido DESPUÉS del timer
            ...

# DESPUÉS (correcto):
func _ejecutar_secuencia(dialogos: Array) -> void:
    for dialogo_config in dialogos:
        # SFX al mismo tiempo que se muestra el diálogo
        if dialogo_config.has("sfx"):
            var audio_manager = get_node_or_null("/root/AudioManager")
            if audio_manager:
                audio_manager.play_sfx(dialogo_config["sfx"])
        if _dialogue_manager:
            _dialogue_manager.mostrar_dialogo(dialogo_config)
            await get_tree().create_timer(dialogo_config.get("duracion", 2.0)).timeout
```
