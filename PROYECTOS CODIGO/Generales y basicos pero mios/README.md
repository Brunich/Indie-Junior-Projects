# Generales y básicos pero míos

Los primeros programas. Python puro, sin dependencias: se ejecutan tal cual.

| Fichero | Qué es |
|---|---|
| `calculadora.py` | Calculadora por consola |
| `adivina_numero.py` | Adivina el número, con pistas de mayor/menor |
| `lista_tareas.py` | Lista de tareas: añadir, listar, completar |
| `piedra_papel_tijera.py` | Piedra, papel o tijera contra la máquina |

```bash
python calculadora.py
```

132 líneas entre los cuatro. Se quedan aquí a propósito: son de donde salió
todo lo demás.
